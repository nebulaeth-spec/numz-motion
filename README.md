# numz: Landing Motion

[Read the interactive article](https://nebulaeth-spec.github.io/numz-motion/)

A short story about the lens metaphor, touch, shared perspective and independent card drift in the numz landing page.

The published article is in English. Its four interactive studies run entirely in the browser, with embedded fonts and no external services. Static SVG studies are included in [the Markdown version](ARTICLE.md).

## Publishing

GitHub Pages serves the root of the main branch. The site is static and requires no build step.

The HTML pages request no indexing. The repository and site are public.

Third-party library and font licenses are retained in [THIRD_PARTY_NOTICES.txt](THIRD_PARTY_NOTICES.txt).
